# Codex 入口指令

请先读取 `REQUIREMENTS.md`、`docs/ASSET_GUIDE.md`，查看 `references/final/` 全部五张设计图，以及 `references/brand/` 品牌原始参考，再检查当前项目目录。

请在当前仓库直接实现一个可运行的 **藏果源五页官网**：首页、果礼定制、商务果切、团餐返图、关于我们。以上述文件为规格，不要重新设计一套全新风格。

最高优先级：
1. 高原蓝 + 暖米白 + 克制藏式纹样，首页保留方案 A 视觉；首页底部旧抽象山峦改为**苹果与高原果园主题的可替换图片区域**。
2. 首页包含果礼和**五个场景**的商务果切入口。
3. 果礼先选系列再看商品；果切先选场景，再选套餐，最后仅在套餐详情选择小/中/大规格。
4. 删去“其他场景推荐”；**任何页面不制作需求填写表单**。
5. 无真实图片、案例、二维码、营业资料的地方使用明确占位，不虚构数据。
6. 运行编译/静态检查，并在可用时通过浏览器检查桌面端与手机端，修正问题后再结束。

交付时列出运行方式、实现文件、页面路径、验证结果与还需补充的素材。
